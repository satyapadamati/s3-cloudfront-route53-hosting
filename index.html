A Simple Learning Path

  1. Git & GitHub — learn branching, PRs, and actions.
  2. Linux & Shell — files, processes, networking.
  3. Docker — images, containers, compose.
  4. CI/CD — Jenkins, GitHub Actions, GitLab CI.
  5. Kubernetes — pods, services, deployments.
  6. Cloud — AWS/Azure/GCP basics & IAM.
  7. Observability — Prometheus, Grafana, ELK/EFK.
  8. Security — secrets, policies, scanning.

Tip: build tiny projects for each step — repetition beats theory.
